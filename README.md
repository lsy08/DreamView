# DreamView

本地照片管理器：读取照片元数据、多种排序筛选、优雅展示、打包导出、陈列柜，并支持手机局域网访问。

## 当前进度

- `prototype/index.html`：前端界面原型（单文件，示例照片由程序生成，用浏览器直接打开即可）
  - 图库：自适应行布局、按时间/评分/焦距/ISO/色调等排序、按月/年/旅程/相机分组、时间轴、筛选
  - 查看器：EXIF 参数卡、直方图、主色提取、评分收藏，键盘 ← → / 0–5 / I / Esc
  - 相册：按旅程自动整理，智能相册规则
  - 陈列柜：美术馆 / 暗厅 / 胶片 / 拍立得四种布展风格，幻灯片放映
  - 选择与打包：Shift 连选、整组选择，导出选项（尺寸、格式、去 GPS、重命名、水印）
  - 手机访问面板（示意）
